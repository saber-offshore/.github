# Saber

**Re-engineering subsea infrastructure.**

Saber builds the subsea-infrastructure platform — engineered to the highest security and quality standards, grounded in established industry references.

We turn specialist design work in marine and offshore engineering — the kind that today lives in spreadsheets, reference PDFs, and tribal knowledge — into auditable, repeatable software. We use AI where it genuinely earns its place, and rely on deterministic methods where numbers need to be right.

It's a domain where mistakes are expensive and certification matters, so correctness, traceability, and reproducibility come first.

## Stack

.NET · ASP.NET Core · PostgreSQL · Azure · Aspire · TypeScript · Next.js
